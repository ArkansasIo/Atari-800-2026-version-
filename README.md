# Atari 800 2026 — Modern Hardware Source

Engineering-oriented source scaffold for the modern Atari 800 2026 hardware concept.

The project targets a modern ARM64-based computer in an Atari 800-inspired chassis with discrete graphics, DDR5/LPDDR5 memory, NVMe storage, FPGA-managed removable cartridge expansion, modern networking, display, USB and embedded-controller power/thermal management.

See `docs/ARCHITECTURE.md`, `docs/POWER_TREE.md`, `docs/CARTRIDGE_PROTOCOL.md`, and `config/board.json` for the initial architecture.

> This repository is an engineering scaffold, not a validated production PCB. High-speed interfaces require SI/PI simulation, controlled-impedance stackups, EMC analysis, thermal validation and vendor reference designs before fabrication.
