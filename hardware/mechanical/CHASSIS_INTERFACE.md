# Chassis / PCB Mechanical Interface

## Concept envelope

- Overall chassis: 330 x 280 x 60 mm nominal
- Motherboard occupies the central lower chassis region
- Rear I/O aligned to the original-style rear panel
- Two top-access cartridge openings
- Cooling inlet/outlet zones must remain unobstructed

## Mounting datum

Define a PCB origin at the lower-left board corner in the mechanical CAD master. All mounting holes, rear I/O cutouts, cartridge connector locations and keyboard mounting points should reference that datum.

## Required mechanical CAD outputs

- STEP assembly
- STEP motherboard
- DXF rear I/O cutout profile
- DXF motherboard mounting pattern
- Cartridge connector datum drawing
- Keyboard switch/matrix mounting drawing
- Fan/heatsink keep-out drawing

No production hole coordinates are fixed by this document; those must be derived from the physical chassis CAD model.
